# LogAnalyzer-AI

**Intelligent Log Analysis & Pattern Detection Tool**

LogAnalyzer-AI is a terminal-themed log analysis platform powered by MiMo V2.5. It provides real-time log viewing, AI-powered pattern detection, and error clustering to help you quickly identify and resolve issues.

## Features

- **Real-Time Log Viewer** — Terminal-style display with syntax highlighting and filtering
- **Pattern Detection** — AI identifies recurring patterns and anomalies in log streams
- **Error Clustering** — Groups similar errors together with frequency analysis
- **Log Level Filtering** — Filter by ERROR, WARN, INFO, DEBUG, and TRACE levels

## Tech Stack

- Vanilla HTML/CSS/JavaScript
- No external dependencies
- Classic terminal theme (green on black)

## Getting Started

Open `index.html` in any modern browser to start analyzing your logs.
